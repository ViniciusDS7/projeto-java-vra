# Projeto Freaky

Sistema de Gestão de Projetos e Equipes desenvolvido em Java utilizando Programação Orientada a Objetos e arquitetura MVC.

## Funcionalidades

- Cadastro de usuários
- Cadastro de projetos
- Cadastro de equipes
- Controle de tarefas
- Gerenciamento de projetos

## Tecnologias utilizadas

- Java
- MVC
- GitHub

## Objetivo

O sistema foi desenvolvido para auxiliar empresas no gerenciamento de equipes, tarefas e projetos, permitindo melhor organização e acompanhamento das atividades.
